Uma API simples e segura

Tudo funciona por HTTPS e JSON. Sem SDK obrigatório: se o seu bot faz requisições, ele fala com o Bup.

Conectar contas

Ligue o usuário do Discord a uma conta Bup com autorização feita pela própria pessoa.

Chave por aplicação

Cada app tem a sua chave. Se vazar, gere outra no painel e a antiga para de funcionar na hora.

Zero senhas no bot

A pessoa autoriza no site do Bup. O bot só recebe ID e nome, nunca senha.

Como funciona

Quatro passos, do app ao usuário conectado.

Crie o appDê um nome, escolha Bot de Discord e Conectar contas.
Pegue a chaveEla aparece uma vez. Guarde em variável de ambiente.
Peça o linkSeu bot chama a API e manda a url para a pessoa.
Receba o resultadoDepois que ela autoriza, a API devolve o ID e o nome dela.

Primeira chamada

Veja a requisição que cria um pedido de conexão.

# POST /api/v1/link
curl -X POST https://SEU-SITE/api/v1/link \
  -H "Authorization: Bearer bup_sk_SUA_CHAVE" \
  -d '{"external_id": "ID_DO_DISCORD"}'
